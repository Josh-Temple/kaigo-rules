# 介護業務改善（prototype）

介護現場の困りごとを起点に、公開事例、論文、公的資料を整理し、改善の選択肢と小さな実験につなげるための別サイトの骨格です。

## Positioning

- **介護ルール**: 制度・基準・通知・Q&Aを正確に確認する
- **介護業務改善**: 現場の困りごとから、改善策・事例・研究を探す
- AIは解決手段の一つとして扱い、AI導入自体を目的にしない

## Vercel

同じ GitHub リポジトリ `Josh-Temple/kaigo-rules` から別 Vercel Project として Import し、Root Directory を `ops-site` に設定する想定です。

推奨プロジェクト名（仮）: `kaigo-ops`

## Current scope

現時点ではUIの骨格のみです。

1. 記録・文書作成
2. 職員教育・引き継ぎ
3. 情報検索・制度改正対応
4. 問い合わせ・連携

実データ、個別製品の推奨、効果数値はまだ掲載していません。
