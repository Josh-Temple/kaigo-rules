# kaigo-rules

介護制度の公開資料を、実務の疑問から公式根拠へ戻れる形で構造化するプロジェクトです。

## MVP scope

- 対象サービス: 通所介護
- 対象範囲: 全国共通事項
- 初期質問: 12問
- AI/Jev: 使用しない
- DB: 使用しない
- 正本: GitHub
- 公開先: Vercel予定

## Design principles

1. 結論より先に根拠の正しさを確保する。
2. 未検証の制度回答は公開しない（fail closed）。
3. 公式原文と当サイトの整理・要約を分離する。
4. 法令・基準省令・報酬基準・通知・Q&A・様式の関係を構造化する。
5. 解釈通知は「最新版の穴あき版 → 過去資料で補完 → 順方向再生で検証」の手順で現行版を再構成する。

## Data

- `data/questions.json`: 実務質問と検索用言い換え
- `data/sources.json`: 公式資料台帳
- `data/notice-nodes.json`: 解釈通知の構造化ノード
- `data/amendments.json`: 改正イベント（初期状態は空）
