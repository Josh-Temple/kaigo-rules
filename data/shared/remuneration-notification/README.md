# Remuneration Notification item-body assurance

This directory is the shared evidence lane for the Remuneration Notification source family.

- `body-fingerprints.json` pins official MHLW consolidated-display documents and service-section bodies by reproducible SHA-256 fingerprints. It intentionally does not duplicate full legal text per service.
- `service-item-body-assurance.json` records source-level evidence separately from service-level projection and evaluates the ten projection invariants.
- A source-section fingerprint alone is not item-body PASS. PASS requires a canonical item body that has been directly compared with the official primary-source body and complete verified coverage of the service-referenced node set.
- Item-body status never promotes currentness, human review, publication, or route exposure.
- Existing NOT_APPLICABLE ingestion states are preserved and are not inferred from this evidence lane.

The evidence is generated by `scripts/build_remuneration_notification_assurance.py` and validated by `scripts/validate_remuneration_notification_assurance.py`.
