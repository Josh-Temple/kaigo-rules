# 通所介護の手引：項目ごとに国の原典を読む構成

読者は通所介護事業所の職員。横浜市の手引は構成の参考とし、読者向けの出典や独自基準の根拠には使わない。

## 表示

- 人員基準は5職種ごとに「基準 → 国の解釈通知 → 国Q&A」を表示する。Q&Aの質問・回答は、その職種の直下で読める。
- 運営基準はサービス開始前、計画作成、提供時、事業所運営の順。設備は室・消防・共用・宿泊・一体的運営に分ける。
- 加算・減算は名称から該当する報酬本文へ進める。国Q&A章は各項目のQ&Aへの索引とする。
- 自作の長い説明や制作・調査の指示、一般的な確認欄の繰り返し、収載件数を本文の中心から外す。人員基準の計算例・任意のチェック欄は補助として残す。
- 横浜市の手引のリンク、市独自の資格案内・併設特例・45分の説明は表示しない。国の原典で確認できる配置・能力・兼務の規定を残す。
- 地域への確認事項は資格の認定範囲、提出書類、事故報告様式などを具体化し、事業所所在地の指定権者等への確認を案内する。

全15章のURL、5職種のアンカー、既存の職種要件へのアンカーを保持する。章の詳細はh1→項目h2→資料種類h3、手引全体では章h2→職種h3→資料種類h4とする。

## 正本と状態

`lib/handbook/dayservice-national-reader.ts`は既存の国の本文を参照する表示用の対応表。本文を生成・言い換えせず、元の条例・通知・報酬・Q&Aデータ、適用範囲、現行性、人手確認・受入状態は変更しない。他38サービスの表示経路は従来のまま。

通知・留意事項は改正資料から整理した未確認の本文を含むため、資料の年・原典リンクと注意を付す。特に介護職員の通知⑤は旧第2項への参照を含むことを明記する。準用条文は第105条の読替えにリンクし、読替え前の原文であると表示する。報酬は参照先の大臣基準・留意事項等の照合未完了を章の冒頭で示す。これらを現行統合本文や独立した法的受入済みの資料と扱わない。

## 検証

`tests/dayservice-national-reader.test.mjs`で出典の解決、国の本文・例外の保持、Q&Aの全文と発出情報、原典リンクの許可範囲、市の参考情報を表示しないことを確認する。`scripts/qa_reader_site.mjs`は実際に描画した手引と各章で市の参考リンクの不在、項目内Q&A、索引からの移動、チェック欄・印刷を検証する。

実Chromeが出力したPDFを目視し、資料の見出しと本文が離れにくい改ページを設定する。人員基準のチェック8項目が同一ページに収まることをPDFの抽出テキストでも検証する。
原典の文中改行を別段落にせず、箇条書きの行頭を段落として扱う。文字列を連結すると原典と完全に一致することを検証する。

通所介護の章は遅延レイアウトの対象から外す。`content-visibility:auto`では、Q&A索引からの移動やフラグメントURLの再読み込み時に、URLだけが変わり質問の表示位置から離れることがあった。実Chromeで対象見出しの座標が画面内にあることまで確認する。
