## 1. 原典と座標の読み方

- **G25:** 厚労省「介護保険施設等における事故予防及び事故発生時の対応に関するガイドライン」（2025年11月、介護保険最新情報Vol.1436、2025-11-07周知） https://www.mhlw.go.jp/content/001591418.pdf 。**冊子p38 / PDF 0起算p40**、冊子p39 / PDF p41、冊子p46 / PDF p48、冊子p27 / PDF p29、冊子p26 / PDF p28、冊子p10 / PDF p12、冊子p6 / PDF p8を再閲覧。主対象は介護保険施設サービス。居宅・居住系への言及は手順共通化の根拠ではない。
- **N24:** 厚労省「介護保険施設等における事故の報告様式等について」（2024-11-29、介護保険最新情報Vol.1332） https://www.mhlw.go.jp/content/001574219.pdf 。**PDF 0起算p1**（旧通知廃止）、p2（報告対象・第一報の時期）、p3（様式対象サービス）を再閲覧。様式の対象とサービスごとの報告制度、自治体の現行運用は別問題。
- 掲載索引: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/hukushi_kaigo/kaigo_koureisha/boushi/kaigo_jiko.html ・ https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/hukushi_kaigo/kaigo_koureisha/boushi/jimurenraku.html 。原典掲載元の確認であり、個別判断の出典にしない。

- 判定の意味: **PASS** は範囲を限定した原典対応が成立、**PARTIAL_WITH_GAPS** は限定説明のみで未検証条件を残す、**NOT_ESTABLISHED** はそのまま公開候補にできない。否定すべき主張を「未確立」と記録する場合、それを支持する出典がないことを示すのであって、医療上の危険度を採点したものではない。
