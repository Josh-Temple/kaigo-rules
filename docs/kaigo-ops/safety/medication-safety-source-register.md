## 4. Worker B/C/Dへ渡すルール

1. **採用できる主張**：`PASS` の記述を、その証拠種別・対象範囲を保持したまま使う。p38〜39の施設の推奨事項を「法律で決まった必須手順」としない。本文には出典と位置を対応させる。
2. **条件付き**：`PARTIAL_WITH_GAPS` は、範囲を限定し未確認点を併記した草案に限る。全業態の公開コンテンツへの昇格は専門職・制度確認後。
3. **使用禁止**：`NOT_ESTABLISHED` の主張（服薬再投与・用量・医療上の危険度・一律の報告要否・事故ゼロ保証・全サービス同一義務）を文章・入力選択肢・結果・印刷物へ混ぜない。
4. **ツール境界**：業務工程、中断、兼務、引継ぎ、変更情報の共有、担当、振り返りを、個人や薬剤を記録しない**選択式の業務プロセス点検**として構想する。処方、薬品、利用者属性、個別事故記録、自由記述、スコア、医療判断、URL/Analytics/保存への回答送信は禁止。
5. **事故発生時の境界**：本サイトが症状・服薬可否・再投与・報告要否を決めない。所属先の事故対応手順、管理者、関係する医療専門職、必要な緊急対応及び自治体の正式手続を優先する一般案内にとどめる。
6. **レビュー前提**：関係する医療職・事故防止実務責任者等のhuman expert reviewは **EXPERT_REVIEW_NOT_DONE**。本台帳単独ではpublic registry/route公開を許可しない。
