## 1. 利用者向け本文案（公開前レビュー対象）

### 困りごと — 服薬業務のどこに見直せる点があるか

**[SOURCE_SUPPORTED: MHLW-02 / MHLW-03]**

服薬に関わる事故は、配薬の準備、配薬、服薬確認など、複数の工程で起こり得ます。別の業務と並行して進めたり、途中で作業が中断したり、担当者や引き継ぎの方法が曖昧だったりすると、確認が難しくなることがあります。

**[DESIGN_PROPOSAL]**

「もっと注意する」で終わらせず、職員が落ち着いて確認できる手順、作業環境、役割分担を事業所で見直すための入口を提供します。個々の薬剤・利用者に関する判断は扱いません。

### なぜ起きるか — 人だけでなく業務条件を見る

**[SOURCE_SUPPORTED: MHLW-02 / MHLW-03 / MHLW-04]**

厚生労働省のガイドラインは、確認不足に加え、他業務との重複、統一されていない業務方法、作業中断、担当者の不明確さや引き継ぎの不足を検討材料に挙げています。事故の分析は当事者だけに任せず、管理者や多職種を含む組織的な取組として行うことを勧めています。

**[DESIGN_PROPOSAL]**

次の問いで現状を整理します。

- 「情報を受け取る」「準備する」「配薬する」「服薬後の確認・記録・引き継ぎをする」のうち、誰が何を担当するか説明できるか。
- 中断や他の依頼が入る場面で、どの作業が止まり、再開時に何を確認するか決まっているか。
- 変更された指示情報が、誰から誰へ、どのように伝わるか分かるか。
- 既存手順と実際の人員・時間・環境との間に無理がないか。

これは**医療上の確認項目ではなく、手順の設計を考えるための問い**です。薬剤の確認方法、本人確認・服薬確認の実施内容、職種ごとの業務範囲は、正式手順と関係する専門職の確認を優先します。

### どこから始めるか — 個人情報を使わず工程を見える化する

**[DESIGN_PROPOSAL]**

実在する事故記録・氏名・薬剤名を使わず、架空の一般的な業務工程を紙などに並べます。

1. 指示変更などの情報を受け取る
2. 配薬準備に関する担当と確認の流れを整理する
3. 配薬・服薬確認に関する担当と引き継ぎの流れを整理する
4. 記録、確認できなかった事項の共有、引き継ぎを整理する
5. 中断・兼務・人の交代が重なる場所を確認する

各工程について「手順を確認できる／確認が必要／見直しが必要／対象外」を整理します。**評価点、事故確率、服薬可否は算出しません。**

**[REVIEW_REQUIRED]**

上記の工程・語彙は施設系ガイドラインを基にした設計案です。サービスによって担当できる業務や実際の工程が異なるため、個別の実施手順として転用する前に関係職種・管理者によるレビューが必要です。

### 小さな改善案 — 施設の正式手順として検討する候補

**[SOURCE_SUPPORTED: MHLW-02 / MHLW-03]**

ガイドラインは、服薬に関わる複数工程を区別した確認、業務中断を減らす環境づくり、職員が服薬業務に専念できる体制、手順書の整備を取り上げています。施設での事例は**実践例**であり、全事業所・全サービスで同じ方法を実施する義務や、改善効果を保証する証拠ではありません。

**[DESIGN_PROPOSAL]**

事業所の管理者と関係職種が、次の候補のうち現場で実行可能なものを検討します。

| 見直し候補 | 事業所で確認すること | 一律に決めないこと |
| --- | --- | --- |
| 作業の中断・再開 | 中断しやすい場面、代わりに対応できる人、再開時の正式な確認手順 | 中断禁止を人員条件に関係なく絶対化しない |
| 担当・役割 | 準備・配薬・確認・記録の担当、交代・不在時の引き継ぎ | ある職種に未確認の業務権限を付与しない |
| 指示変更の連携 | 変更情報の受領先、最新版の参照先、伝達の確認方法 | サイトが処方内容の正誤を判定しない |
| 複数段階での確認 | 現行マニュアル、関係職種の役割、確認の実施可能性と負担 | すべてのサービスに同一人数・同一方法を義務化しない |
| 教育と振り返り | 新規職員・交代時の説明、手順変更を伝える先、再評価時期 | 「注意喚起したから解決」と判定しない |

### 確認しておくこと — サイトの役割と判断の境界

**[REVIEW_REQUIRED]**

- 事業所の正式な業務手順、役割分担、教育方針を確認してください。医師・薬剤師・看護職員など関係する専門職の判断が必要な事項は、その職種と調整してください。
- 服薬の要否、用量、時刻、薬剤の組み合わせ、飲み忘れ・誤薬後の再投与などは**このサイトでは判断しません**。
- 事故や服薬上の疑義がすでに発生している場合は、本人の安全確保を優先し、所属先の正式な事故対応手順、管理者・関係する医療専門職への連絡、必要な緊急対応、法令・自治体の報告ルールに従ってください。症状や薬剤による条件分岐は提供しません。
- 本人の意思・尊厳・自立支援も踏まえて運用を検討してください。服薬拒否などを一律に「不適切」と判定しません。
- このページは**制度適合を判定せず**、当該サービスの法令・基準・通知はKaigo Rulesの検証状態と一次資料で確認してください。

### 振り返り — 手順を増やして終わらせない

**[SOURCE_SUPPORTED: MHLW-04]**

ガイドラインは、原因の分析・再発防止策の検討に組織として取り組み、一定期間後に対策の効果を検証し、必要に応じて見直すことを勧めています。

**[DESIGN_PROPOSAL]**

振り返り時に、対応する役割（個人名不要）、手順を変えた日、次の確認日、想定外の業務負担、未解決の連携事項を確認します。**ヒヤリ・ハット件数の単純な増減だけで安全効果を断定しません。** 既存の正式な事故分析・報告手順を、このサイトの簡易シートで置き換えません。
