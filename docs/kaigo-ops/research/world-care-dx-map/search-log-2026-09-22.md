# Search Log — World Care DX / AI Map

実施日: 2026-09-22

## 目的

世界の介護・高齢者ケアにおけるDX・AI活用について、初回ランドスケープを作る。

今回の目的は完全網羅ではなく、

- 分類が妥当か
- 主要国で何が実装されているか
- 学術Evidenceがどこまであるか
- 次に深掘りすべきIssueは何か

を確認すること。

## 優先したsource

1. 政府・国際機関
2. systematic review / meta-analysis
3. 公共部門のcase study
4. provider case presented via official channel
5. vendor materialは初回では原則として補助扱い

## Limitations

- 公開Web情報を中心としたfirst-pass。
- vendor-reported outcomeは網羅していない。
- paywalled論文はabstractベースとなる場合がある。
- 同じ「介護」でもresidential care / home care / adult social care / healthcareが混在するため、settingは今後source registerでより厳密に分ける。
- 国ごとの制度差を考慮せず、導入事例だけで日本への有効性を判断しない。
