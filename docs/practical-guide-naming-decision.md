# 実務ガイド 名称決定記録

Date: 2026-10-06
Worker: C — Practical Guide / Task-Oriented Product Worker

## 決定

今回のworking labelは **「実務ガイド」** とする。

## 比較

- **実務ガイド**: 初見で用途を理解しやすく、開設・運営・報酬・届出等へ拡張しやすい。一方で公式手引きと誤認されないよう、サイト独自の案内である旨を明示する。
- **実務ナビ**: 軽く親しみやすいが、制度根拠を扱うページとしてはやや抽象的。
- **制度ガイド**: 制度情報であることは明確だが、利用者の「実務の目的から探す」という使い方が弱く見える。
- **手続・基準ガイド**: 内容は具体的だが、国Q&Aや報酬・加算まで含める将来範囲を狭く見せる。
- **開設・運営ガイド**: 開設前の利用には分かりやすいが、既存事業所の報酬・変更届・Q&A探索まで含めにくい。

## 表示上の安全条件

- 「公式な解釈」「個別案件の判断」を提供するページとして見せない。
- 複数法源を合成した未レビュー結論を本文で生成しない。
- ガイドの役割は、公開済みDBの該当情報と公式資料への導線を示すこととする。
- 公式資料・適用範囲・現行性に関する注意は、利用者が確認できる形で残す。
