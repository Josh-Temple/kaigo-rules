# 入口・原資料導線の改善（2026-10-02）

## 実装範囲

- 入口の公開資料説明をサービスカタログの登録層から生成し、通所リハの4層を案内する。
- 検索でFAQに対応する根拠とキーワード直接一致を区別し、relation内部名を利用者向けの役割に置き換える。
- 通所リハ算定留意事項の4論点に目次を設け、各主項目から公式令和6年PDFの掲載ページへリンクする。
- 既存の毎週月曜・手動の留意事項監視ワークフローに、通所リハ報酬・留意事項の公式資料再解析を加える。

本文・版・サービス適用範囲・検証状態は変更しない。資料再解析PASSは現行性や人手確認を証明しない。改正監視は既知資料・既存索引に限られ、後続改正の網羅性は未確定。
