# 通所介護手引の読みやすさ・使いやすさの改善

## 対象と目的

2026年10月30日の公開画面と横浜市の令和8年6月版手引の比較を受けた修正。
対象は通所介護の表示。基点は main `41decf9c2f08c1a9ed6535439d2ac9dc2229a384`。
ローカルで取得済みのソースツリー `a13cf25337a9ead9855bcad3116044e9ddf58923` が、GitHubの同コミットのツリーと一致することを確認した。

## 変更

- 報酬の出典位置に混入していた告示本文を表示位置情報から除き、本文の二重表示を解消。
- 通常規模型・大規模型I・大規模型IIの基本報酬を、所要時間×要介護度の表にする。6区分×5介護度がそろわない入力は表に変換しない。元の全文は別途開ける。
- 国の列挙事項・計算式を段落として分ける。段落を再連結すると元の文字列と一致する。
- 第105条で準用する条文について、通所介護のサービス名・明示された読替えを反映した閲覧用表示を用意。編集した表示であることを明記し、読替え前の原文と第105条への導線を残す。
- 運営基準の異なる業務を分け、苦情処理、会計の区分、広告、秘密保持、管理者の責務、運営規程等へ個別に移動できるようにする。既存の固定リンクIDは維持。
- 公開済みの別告示データにある大臣基準11項目を該当加算の中に表示。現行性・適用関係の照合未完了は残す。未収載の大臣基準を推測して補わない。
- 国Q&Aを7問から10問へ増やす。生活相談員には提供時間数とサービス担当者会議、看護職員・機能訓練指導員には兼務のQ&Aを配置。
- 介護職員の20人・5時間の計算例と、2名が9時〜14時に勤務する場合の配置例を併記。配置計算の計画上の時間と実績の区別をチェック欄から案内。
- 同一項目内で繰り返す省令の正式名称を減らし、各条文への公式リンクは維持。

## 検証と限界

- 手引テスト92件に成功。基本報酬90セルの値の保持、未知の表形式での原文表示、準用表示の数値・原文保持、別告示全文と未確認表示の保持を含む。

- 全資料の施行版・後続改正の確認や、全加算の要件が完全であるとの判断は行っていない。原典の取得・本文の照合と、法的適用の確定は区別する。
