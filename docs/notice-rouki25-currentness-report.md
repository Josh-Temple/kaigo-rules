## 1. 令和6年度資料のcheckpoint判定

厚生労働省の[令和6年度介護報酬改定ページ](https://www.mhlw.go.jp/stf/newpage_38790.html)で、「基準省令に関する通知（解釈通知等）」の「解釈通知（居宅）」に掲載される次のPDFを取得・確認した。

- PDF: [指定居宅サービス等及び指定介護予防サービス等に関する基準について](https://www.mhlw.go.jp/content/12300000/001227935.pdf)
- SHA-256: `eebad7611a307f02205dce894a5375634f8f84ca66d8555c9a9da0085750e4b4`
- サイズ: 1,433,351 bytes、79ページ
- PDF埋込作成日時: 2024-03-14 15:03:55 EDT（日本時間2024-03-15 04:03:55）。親ページには日単位の掲載・更新時刻が表示されないため、資料日付のproxyは3月15日、coverage開始日はさらに1日早い3月14日とした。
- PDFに印字される通知番号: 平成11年9月17日老企第25号。今回確認した抄録内に、R6改正通知固有の発出番号は印字されていない。
- 文書の性質: 「（抄）」と明記された改正新旧対照表。左が「新」、右が「旧」。統合全文ではない。
- 通所介護: 第3・六の通所介護部分は含むが、未改正部分は「1・2（略）」等で省略される。

したがって、このPDFを `R6_OFFICIAL_FULLTEXT_CHECKPOINT` とは認定しない。R6改正箇所を示す公式の部分一次資料として扱う。可視の改正断片に対応する「基本取扱方針」「業務継続計画」「衛生管理等」「準用」の4 candidateは、目視できる範囲で具体的な矛盾を認めなかった。ただし、candidate全体の一致を証明するものではない。残る18 candidateは未改正本文が省略されるため、このPDFから直接照合できない。

既存snapshotにある別PDF [001453049.pdf](https://www.mhlw.go.jp/content/12304250/001453049.pdf)（SHA-256 `36dbf483345fa9e9512f6610249989ef4b4acbe8daa19030c12e2220a8a66791`）も確認した。PR #88で出所を再確認し、確認できる最古の公式親ページ掲載文脈は令和7年3月改訂（周知通知2025-03-25）と整理した。令和8年3月改訂ページでも同じPDF URLが再掲されている。PDF自体は抄・新旧対照表であり、親ページ掲載時期をPDF内新旧対照表そのものの正式改正日とは扱わない。この資料をcurrent full textや改正不存在の根拠にはしない。

## 5. 再利用validatorと検証

`scripts/validate_notice_rouki25_currentness_ledger.py` を追加し、`npm run validate:data` に接続した。validatorは次を検出する。

- candidate本文とpacketに記録されたSHA-256の不整合、または監査後のcandidate hash変更
- R6 PDFのURL・manifest SHA-256変更
- R6 checkpointに含めた4改正イベントの追加・削除・内容変更
- `notice-amendment-events.json` の変更
- 全22項目、分類件数、HUMAN_VERIFIED / VERIFIED_CURRENT無効化の破り
- coverage_endを過ぎたcurrentness結論の期限切れ（HOLDは警告を出して保持し、PASS系なら失敗）

CIは検索結果の不存在を永続的に証明しない。入力資料が変わったときに台帳の再確認が必要だと知らせ、coverage_endを過ぎた判断を失効扱いにする。
