# 通所介護手引の見出し・項目内移動の改善

## 対象

2026年10月30日の継続改善。GitHub main `3660a6f9e9fac7de7534d01a1e46462b463d5ee0` と作業用ソースのツリー `97e87405ebef2676224d5a73191c5fd3246c4c3f` の一致を確認した。

事業所職員が、加算名や職種から必要な規定・国Q&Aへ移動して読む流れを対象とする。

## 変更と理由

- 大臣基準の正式名称は原文内に残し、別途繰り返していた見出しを省く。ルビの改行で途中までになっていた見出しも読者向け表示から除く。
- 加算名と報酬告示の見出し、基本報酬表の名称を重複表示しない。報酬部分の小見出しは「報酬告示」として資料の種類を明確にする。
- 複数の資料があり、国Q&Aまたは大臣基準を含む項目には、項目内の移動リンクを追加する。既存の項目・Q&Aへの固定リンクは維持する。
- 報酬表を横にスクロールしても所要時間の列を表示し、数値と時間区分を見比べられるようにする。印刷時は固定表示を解除する。
- 原典の空白だけからなる段落を画面上の余白にしない。本文を含む段落や原典データは変更しない。
- 各章の末尾で二重になっていた前後の章への案内を、章ページ共通の一つにまとめる。目次へ戻るリンクは残す。
- 国Q&Aの出典案内は、発出PDFとQ&A集の両方を含む実際のリンクに合わせて記述する。
